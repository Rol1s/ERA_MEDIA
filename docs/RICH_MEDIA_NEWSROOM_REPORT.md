# Rich Media Newsroom v1

Дата: 2026-05-15

## Что добавлено

Добавлен медиа-первый режим подготовки постов для MAX: картинка/превью сверху, затем жирный заголовок и короткий текст.

## Приоритет медиа

1. Реальное preview из источника: `og:image`, `twitter:image`, `media:content`, `media:thumbnail`, `enclosure`.
2. Официальное preview помечается как `official`, остальные как `source_preview`.
3. Для низкорисковых тем без фото допускается generated editorial card.
4. Для высокорисковых тем без реального медиа генерация блокируется: статус `needs_review`, причина `source_media_required`.

## Безопасность

Сгенерированная картинка никогда не считается доказательством события. Для войны, ЧС, детей, судов, политики, медицины, смерти, обвинений и похожих тем система требует реальное/официальное медиа или ручной выбор.

## MAX-упаковка

- Заголовок всегда жирный.
- Источник выводится один раз.
- RSS/XML ссылки не показываются читателю.
- Кнопки: `Предложить новость`, `Подписаться на канал`.

## Что не делаем в v1

- Не подделываем карты, кадры боевых действий и фото людей.
- Не генерируем “документальные” изображения.
- Не обещаем реакции/счётчики: это механика MAX, не наша.
